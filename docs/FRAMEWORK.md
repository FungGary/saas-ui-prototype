# 线上娃娃机SAAS系统 - UI框架规范

## 一、技术栈

### 1.1 前端框架
- Vue 3 (Composition API)
- TypeScript
- Vite

### 1.2 UI组件库
- Element Plus ^2.0.0

### 1.3 样式方案
- Element Plus 默认主题
- Tailwind CSS 3.x (辅助布局)

---

## 二、布局规范

### 2.1 整体布局
```
┌─────────────────────────────────────────────────────┐
│  Top Header (面包屑、用户信息、通知等)               │
├──────────┬─────────────────────────────────────────┤
│ Sidebar  │                                         │
│  (导航)  │         Main Content Area               │
│          │                                         │
│          │                                         │
│          │                                         │
└──────────┴─────────────────────────────────────────┘
```

### 2.2 侧边栏
- 宽度: 200px
- 背景色: #001529 (使用 CSS 变量 --color-sidebar-bg)
- 文字颜色: rgba(255,255,255,0.65)
- 选中状态背景: #409eff (使用 CSS 变量 --color-sidebar-active)

### 2.3 主内容区
- 背景色: #f0f2f5
- 内容卡片: 白色背景，圆角8px，阴影

---

## 三、颜色规范

### 3.1 主色调
| 颜色 | 值 | CSS变量 | 用途 |
|------|-----|---------|------|
| 主蓝 | #409eff | --color-primary | 按钮、链接、选中状态 |
| 深蓝 | #001529 | --color-sidebar-bg | 侧边栏背景 |
| 成功 | #67c23a | --color-success | 成功状态、通过审核 |
| 警告 | #e6a23c | --color-warning | 警告提示 |
| 危险 | #f56c6c | --color-danger | 删除按钮、失败状态 |
| 信息 | #909399 | --color-info | 信息提示 |

### 3.2 文字颜色
| 类型 | 值 | CSS变量 | 用途 |
|------|-----|---------|------|
| 主文字 | #303133 | --color-text-primary | 标题、主要内容 |
| 次文字 | #606266 | --color-text-regular | 次要内容 |
| 轻文字 | #909399 | --color-text-secondary | 辅助说明 |
| 占位符 | #c0c4cc | --color-text-placeholder | 占位文字 |
| 禁用 | #c0c4cc | --color-text-placeholder | 禁用状态 |

### 3.3 表格颜色
| 类型 | 值 | CSS变量 |
|------|-----|---------|
| 表头背景 | #f5f7fa | --color-table-header |
| 行高 | 48px | - |
| 斑马纹 | 支持 | - |

| 类型 | 大小 | 用途 |
|------|-----|------|
| 页面标题 | 20px | 页面主标题 |
| 卡片标题 | 16px | 卡片、模块标题 |
| 正文 | 14px | 主要内容文字 |
| 辅助文字 | 12px | 说明、提示文字 |

## 五、间距规范

| 间距 | 值 | 用途 |
|------|-----|------|
| 页面边距 | 24px | 内容与边界距离 |
| 卡片间距 | 16px | 卡片之间距离 |
| 元素间距 | 8px/12px | 表单元素间距 |

## 六、组件规范

### 6.1 按钮
- 主按钮: 蓝色背景，白色文字
- 次按钮: 白色背景，灰色边框
- 文字按钮: 仅文字，无边框

### 6.2 表格
- 使用 el-table
- 表头背景: #f5f7fa (使用 CSS 变量 --color-table-header)
- 行高: 48px
- 支持斑马纹

### 6.3 表单
- 使用 el-form + el-form-item
- 标签宽度: 120px
- 必填字段标红 *

### 6.4 弹窗
- 使用 el-dialog
- 宽度: 500px (默认)
- 标题加粗

### 6.5 抽屉
- 使用 el-drawer
- 宽度: 400px (默认)

### 6.6 标签
- 使用 el-tag
- 状态标签使用对应颜色

---

## 七、图标规范

- 使用 Element Plus 内置图标
- 图标颜色与文字一致
- 图标尺寸: 16px/20px/24px

---

## 八、状态样式

### 8.1 状态标签颜色
| 状态 | 颜色 |
|------|-----|
| 正常/启用 | 绿色 |
| 禁用 | 灰色 |
| 待审核 | 橙色 |
| 已通过 | 绿色 |
| 未通过 | 红色 |
| 进行中 | 蓝色 |
| 已完成 | 绿色 |

### 8.2 空状态
- 使用 el-empty
- 显示"暂无数据"提示
- 提供操作引导

### 8.3 加载状态
- 使用 el-skeleton 或 v-loading
- 页面加载显示骨架屏

---

## 九、数据格式

### 9.1 日期格式
- 显示格式: YYYY-MM-DD HH:mm:ss
- 日期选择器: 支持范围选择

### 9.2 金额格式
- 保留两位小数
- 显示货币符号: ¥

### 9.3 手机号格式
- 脱敏显示: 188****8888

## 十、代码规范

### 10.1 文件命名
- 页面: xxxPage.vue
- 组件: xxxComponent.vue / xxxForm.vue / xxxTable.vue
- Mock数据: xxxMock.ts

### 10.2 组件结构
```vue
<template>
  <!-- 模板内容 -->
</template>

<script setup lang="ts">
// 脚本逻辑
</script>

<style scoped>
/* 组件样式 */
</style>
```

### 10.3 类型定义
- 使用 interface 定义数据类型
- 禁止使用 any
- Mock数据应有类型标注
