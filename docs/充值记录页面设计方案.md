# 充值记录页面优化后的字段顺序 + 页面布局方案

## 一、页面定位

页面名称：**充值记录**

页面用途：用于站点端查看用户充值订单、商户归属、充值内容、支付金额、退款状态，并支持财务查询、对账和导出。

页面规则：

```text
1. 不考虑异常情况
2. 退款只有全额退款
3. 订单号拆分为内部订单号、外部订单号
4. 增加商户信息
5. 增加充值内容
6. 统计区字段为：充值总金额、实付金额、充值退款金额、支付宝充值金额、微信充值金额
```

# 三、筛选查询区字段顺序

## 3.1 筛选字段顺序

| 顺序 | 字段    | 控件类型       | 说明                   |
| -- | ----- | ---------- | -------------------- |
| 1  | 商户信息  | 输入框 / 下拉搜索 | 支持商户名称、商户编号、站点名称搜索   |
| 2  | 用户信息  | 输入框        | 支持昵称、UID、用户编号搜索      |
| 3  | 时间类型  | 下拉选择       | 创建时间、支付时间、退款时间       |
| 4  | 时间范围  | 日期时间范围选择器  | 根据时间类型筛选             |
| 5  | 内部订单号 | 输入框        | 平台系统内部订单号            |
| 6  | 外部订单号 | 输入框        | 微信 / 支付宝 / 三方支付订单号   |
| 7  | 订单状态  | 下拉选择       | 全部、未支付、已支付、已关闭       |
| 8  | 退款状态  | 下拉选择       | 全部、未退款、已退款           |
| 9  | 支付方式  | 下拉选择       | 全部、支付宝、微信            |
| 10 | 订单来源  | 下拉选择       | 全部、H5、小程序、App、公众号、后台 |

---

## 3.2 筛选区布局

第一行放高频查询项：

```text
商户信息｜用户信息｜时间类型｜时间范围｜内部订单号
```

第二行放订单类筛选项：

```text
外部订单号｜订单状态｜退款状态｜支付方式｜订单来源｜重置｜查询
```

按钮规则：

| 按钮 | 样式   | 说明             |
| -- | ---- | -------------- |
| 重置 | 普通按钮 | 清空当前筛选条件       |
| 查询 | 主按钮  | 按当前条件查询列表和统计数据 |

# 四、数据统计区字段顺序

## 4.1 统计字段顺序

| 顺序 | 字段      | 统计口径                       |
| -- | ------- | -------------------------- |
| 1  | 充值总金额   | 已支付充值订单的充值金额合计             |
| 2  | 实付金额    | 用户实际支付金额合计，扣除随机立减 / 优惠后的金额 |
| 3  | 充值退款金额  | 已全额退款订单的退款金额合计             |
| 4  | 支付宝充值金额 | 支付方式为支付宝的实付金额合计            |
| 5  | 微信充值金额  | 支付方式为微信的实付金额合计             |

---

## 4.2 统计区展示顺序

```text
充值总金额｜实付金额｜充值退款金额｜支付宝充值金额｜微信充值金额
```

页面展示示意：

```text
┌────────────┐ ┌────────────┐ ┌──────────────┐ ┌──────────────┐ ┌────────────┐
│ 充值总金额  │ │ 实付金额    │ │ 充值退款金额  │ │ 支付宝充值金额 │ │ 微信充值金额 │
│ ¥5,900.40  │ │ ¥5,890.06  │ │ ¥10.00       │ │ ¥2,300.00    │ │ ¥3,590.06  │
└────────────┘ └────────────┘ └──────────────┘ └──────────────┘ └────────────┘
```

建议统计区右上角增加口径说明：

```text
充值总金额：仅统计已支付充值订单金额
实付金额：充值金额 - 随机立减 / 优惠金额
充值退款金额：仅统计已全额退款订单金额
支付宝充值金额：支付宝支付订单的实付金额
微信充值金额：微信支付订单的实付金额
```

# 五、订单列表字段顺序

建议使用**聚合式表格字段**，不要全部平铺，否则字段过多，页面会很宽。

## 5.1 表格字段顺序

| 顺序 | 表格字段 | 展示内容                |
| -- | ---- | ------------------- |
| 1  | 订单信息 | 内部订单号、外部订单号、创建时间    |
| 2  | 商户信息 | 商户名称、商户编号、站点名称      |
| 3  | 用户信息 | 头像、昵称、UID、用户编号      |
| 4  | 充值内容 | 充值套餐、到账币种、到账数量、赠送数量 |
| 5  | 金额信息 | 充值金额、随机立减、实付金额      |
| 6  | 支付信息 | 支付方式、订单来源、支付时间      |
| 7  | 订单状态 | 未支付、已支付、已关闭         |
| 8  | 退款状态 | 未退款、已退款             |
| 9  | 操作   | 查看详情、复制             |

---
