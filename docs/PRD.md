# 线上娃娃机SAAS系统 - 产品需求文档

## 一、项目概述

### 1.1 项目背景
本系统是一个线上娃娃机SAAS管理平台，为运营商提供完整的娃娃机游戏运营管理能力。

### 1.2 核心目标
- 提供完整的房间管理能力
- 实现用户互动与客服支持
- 完善财务管理与订单追踪
- 支持数据分析与决策支持

### 1.3 目标用户
- 平台管理员
- 客服人员
- 财务人员
- 运营人员

---

## 三、技术架构

### 3.1 前端技术栈
- Vue 3 + TypeScript
- Element Plus UI组件库
- Vite构建工具
- Vue Router路由管理

### 3.2 设计规范
- 采用Element Plus默认主题
- 蓝色主色调 (#1890ff)
- 深色侧边栏 (#001529)
- 响应式布局设计

---

## 四、数据模型

### 4.1 用户数据
```
用户ID, 用户昵称, 头像, 手机号, UID, 状态
```

### 4.2 房间数据
```
房间号, 房间名称, 房间封面图, 玩法类型, 房间功能, 游戏币, 投币时间
```

### 4.3 订单数据
```
订单号, 用户ID, 商品信息, 数量, 金额, 状态, 创建时间
```

## 五、交互规范

### 5.1 通用交互
- 点击按钮有反馈
- 表单有验证
- 弹窗支持关闭/取消/确认
- 操作成功/失败有提示

### 5.2 表格交互
- 支持筛选、搜索、分页
- 支持操作列（编辑、删除、详情等）
- 空状态有提示
